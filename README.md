# 블로그 글 올리는 법
- 올리기 전 `humanize-korean-lite` 스킬로 AI 말투를 다듬습니다.

- 글은 `_posts/YYYY-MM-DD-영문-주소.md` 파일 하나입니다. 맨 위에 `layout: post`, `title`, `date`를 적습니다.
- 그림은 `assets/img/` 아래에 두고 글에서 `![설명](/assets/img/파일.png)`로 부릅니다.
- main에 올리면 GitHub Pages가 1~3분 뒤 https://wh209302.github.io 에 반영합니다.
- 올리기 전 확인: 비밀값·개인정보·아직 공개하지 않을 기획이 들어 있지 않은지.
